## Overview

GUI Tester to an experiment in trying to see if, using the windows API, I can test a GUI application, through statements defined in a sub set of Pascal style language.

## Usage

At this moment, the language is defined in a BNF grammar file. If it proves that it will do what I want, I'll write a HTML Help file.

There are various statements that can be types to Launch the app, find windows, send keys, etc. The statements are defined in a simple list which is executed from top to bottom. You cannot define sub routines to collate statements.

## Project State

This is a little more than a prototype but still an experiement to see if this can be done.
